# Declaración de Uso de Inteligencia Artificial

Durante el desarrollo de este Avance 2, se utilizó IA (modelo Gemini) como asistente de soporte técnico y Pair-Programming, específicamente en las siguientes áreas:

1. **Depuración de Código Python:** Identificación y resolución de errores de sintaxis (`SyntaxError`) e indentación en el archivo `app.py` relacionados con la integración de la librería Boto3.
2. **Implementación de Seguridad (S3):** Asistencia en la lógica de programación para generar correctamente las *Presigned URLs* en el backend, permitiendo mantener el bucket de AWS S3 en modo privado.
3. **Soporte de Infraestructura y Git:** Guía paso a paso para la resolución de conflictos de autenticación con el *Personal Access Token* de GitHub, limpieza de archivos ocultos de sistema Linux (`.ssh`, `.bash_history`) para prevenir fugas de información, y comandos de Docker Compose (`build`, `logs`) para forzar la actualización de los contenedores.
